# 📈 Stock Finder

KOSPI·KOSDAQ 전 종목을 공개 데이터로 수집해 **팩터 점수로 스크리닝**하는 로컬 우선(local-first)
웹앱입니다. Docker·회원가입·유료 API 키 없이 `npm run dev` 하나로 돌아갑니다.

> ⚠️ **투자 참고 도구이며 투자 권유가 아닙니다.** 모든 점수·시그널은 참고 자료입니다.
> 주식 투자는 원금 손실이 가능하며 최종 결정과 그 결과는 사용자 본인의 책임입니다.
> 자세한 내용은 아래 [고지](#고지) 참고.

---

## 빠른 시작

```bash
git clone https://github.com/YoobinJeon/stock-finder.git
cd stock-finder
npm install
npm run dev
```

브라우저에서 <http://localhost:5173> 이 열립니다.

1. 좌측 메뉴 **[🔄 데이터]** 로 이동
2. **"시총 상위 200"** 선택 후 수집 시작 (실측 **약 45초**)
3. 수집이 끝나면 **[🔍 스크리너]** 에서 점수·필터로 종목을 걸러봅니다

> 📖 **처음이시라면 [GETTING_STARTED.md](GETTING_STARTED.md) 를 보세요** —
> 데이터 수집부터 화면별 사용 순서, 자주 막히는 곳까지 정리했습니다.

DB는 별도 설치가 필요 없습니다 — [PGlite](https://pglite.dev)(파일 기반 임베디드 Postgres)를
쓰며 데이터는 `server/data/` 에 저장됩니다.

### 실행 스크립트

| 명령 | 설명 |
|---|---|
| `npm run dev` | 서버(:4000, tsx watch) + 클라이언트(:5173, vite) + dist watch 빌드 |
| `npm run serve` | 클라이언트 빌드 후 단일 프로세스로 서빙 (:4000) |
| `npm run typecheck` | 서버·클라이언트 `tsc --noEmit` |
| `npm test` | `node:test` 단위 테스트 |
| `npm run pipeline -- --scope=top200` | CLI로 수집 (스코프는 [ARCHITECTURE.md](ARCHITECTURE.md) 참고) |

> ⚠️ **PGlite는 단일 프로세스 전용입니다.** dev 서버가 떠 있는 동안 `migrate`/`pipeline`
> 스크립트를 별도 프로세스로 돌리지 마세요 — DB가 잠깁니다. 서버 실행 중에는
> `POST /api/v1/data/refresh` API를 쓰면 됩니다.

## 점수 산정 (0~100)

가중 합산이며, 가중치는 `algorithm_configs` 테이블에서 배포 없이 조정할 수 있습니다.

| 팩터 | 기본 가중치 | 내용 |
|---|---|---|
| 가치 | 30% | PER·PBR·배당수익률, 일회성 이익 왜곡 감지 |
| 퀄리티 | 25% | ROE·영업이익률·부채비율·이익의 질(3개년 시계열) |
| 성장 | 20% | 매출·EPS YoY, 일회성 급증·기저효과 반등 감지 |
| 모멘텀 | 15% | 1·3개월 수익률·RSI·크로스섹션 RS 백분위·거래대금 급증 |
| 신기술 | 10% | 섹터 기술성 + 종목명·업종 키워드 |
| 수급 | 0% (기록만) | 외인·기관 순매수·연속일·OBV — 검증 후 활성화하도록 시드 |

보정·제외 규칙(초소형주 수축, 위험종목 30점 캡, 공시 이벤트 가감점, 데이터 커버리지 수축)과
각 팩터의 세부 산식은 [ARCHITECTURE.md](ARCHITECTURE.md) 를 참고하세요.

모든 점수에는 실수치 근거가 붙습니다 (종목 상세 → 점수 분석).

## 데이터 출처

전부 공개·무료 소스이며, 기본 동작에는 **API 키가 필요 없습니다.**

| 소스 | 데이터 | 키 |
|---|---|---|
| 네이버 금융 | 종목 목록·시세·연간/분기 재무·컨센서스·업종·투자자별 수급·지수·테마·ETF·뉴스 | 불필요 |
| Yahoo Finance | 해외 지수·심볼 차트, 국내 일봉 폴백 | 불필요 |
| DART OpenAPI | 공시 목록·이벤트 분류, 분기 실적 이력 백필 | `DART_API_KEY` (선택) |
| KRX 정보데이터시스템 | 투자자별 순매수대금(세부 8주체 공식 금액) | `KRX_ID`/`KRX_PW` (선택) |
| 한국투자증권 OpenAPI | 국내 일봉(수정주가 정본)·신용잔고·야간선물 | KIS 앱키 (선택) |

선택 키는 `.env.example` 을 `server/.env` 로 복사해 설정합니다. 설정하지 않으면 해당 기능만
건너뛰고 나머지는 정상 동작합니다.

**수집 예절**: 요청 사이에 `sleep`을 넣어 과부하를 피하도록 구현되어 있습니다. 비상업적 개인
이용 범위에서 사용하시고, 각 소스의 이용약관을 확인하세요.

## 자동 갱신

`server/.env` 에 크론 표현식을 넣으면 스케줄 수집이 켜집니다 (미설정 시 비활성).

```bash
CRON_REFRESH=10 18 * * 1-5         # 평일 18:10 전체 수집
CRON_REFRESH_EARLY=50 15 * * 1-5   # 평일 15:50 마감 직후 시세·점수만
CRON_REFRESH_CATCHUP=5 19-23 * * 1-5  # 누락 슬롯 소급 실행
```

스케줄러는 인프로세스 타이머라 프로세스가 꺼져 있으면 그 슬롯을 건너뜁니다 — 캐치업 크론과
부팅 시 점검이 이를 보완합니다. 전체 목록은 `.env.example` 참고.

## 원격 접속 (선택)

서버(:4000)는 모든 인터페이스에 바인딩되고 빌드된 화면까지 함께 서빙하므로, 같은 네트워크의
다른 기기에서 바로 열 수 있습니다.

```bash
npm run serve   # 화면 빌드 + 단일 서버(:4000)
```

신뢰할 수 없는 네트워크(공개 인터넷, 터널링 등)에 노출한다면 **반드시** `server/.env` 에
`ACCESS_PASSWORD` 를 설정하세요 — 앱 전체에 Basic Auth 한 겹이 걸립니다. 미설정 시 서버가
부팅할 때 경고 로그를 남깁니다.

레이트리밋(전역 분당 300 + 무거운 엔드포인트 분당 10)과 CSP가 기본 활성화되어 있습니다.

## 프로젝트 상태

이 저장소는 개인 프로젝트를 정리해 **공유 목적으로 공개한 스냅샷**입니다.
적극적인 유지보수나 이슈·PR 대응은 하지 않습니다. 자유롭게 포크해서 쓰세요.

외부 웹사이트를 스크레이핑하므로 **소스 측 HTML·API가 바뀌면 파서가 깨질 수 있습니다.**
동작을 보장하지 않습니다.

**최종 검증 2026-08-16** (깨끗한 클론 기준): typecheck 오류 0 · 테스트 826건 통과 ·
빌드 성공 · `top200` 수집 44초 200/200 실패 0 · 화면 API 18종 정상.
상세는 [GETTING_STARTED.md](GETTING_STARTED.md#검증-이력-2026-08-16-깨끗한-클론) 참고.

### 알려진 의존성 취약점

스냅샷 시점의 `package-lock.json` 에 남아 있는 항목입니다. 전부 **메이저 버전 업그레이드가
필요해** 적용하지 않았습니다 — 포크해서 쓰신다면 직접 올리시길 권합니다.

| 패키지 | 등급 | 영향 범위 |
|---|---|---|
| `vite`, `esbuild` | high / moderate | **개발 서버 전용.** `npm run serve` 는 미리 빌드된 정적 파일을 Express로 서빙하므로 운영 경로에는 해당 없음 |
| `react-router`, `react-router-dom` | moderate | `<Link>`·`useNavigate` 의 백슬래시 오픈 리다이렉트. 이 코드베이스는 이동 대상이 전부 하드코딩 경로라 **도달 경로 없음** |

## 고지

- 이 소프트웨어는 **투자 참고 도구**이며, 투자 권유·추천·자문이 아닙니다.
- 모든 점수·시그널·백테스트 결과는 참고 자료입니다. 과거 데이터 기반 분석이 미래 수익을
  보장하지 않습니다.
- 백테스트에는 거래비용·세금·슬리피지가 반영되어 있지 않습니다.
- 데이터의 정확성·완전성·적시성을 보장하지 않습니다. 실제 판단 전 원본 공시·재무제표를
  직접 확인하세요.
- 주식 투자는 원금 손실이 가능하며, 최종 결정과 그 결과는 전적으로 사용자 본인의 책임입니다.
- 작성자는 이 소프트웨어의 사용으로 발생한 어떤 손실에도 책임지지 않습니다.
